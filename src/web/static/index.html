Where results get sent

—

The Discord channel each sweep posts its picks to. In Discord: Edit Channel → Integrations → Webhooks → Copy Webhook URL.

This URL is a password in disguise — anyone holding it can post to the channel — so it is stored in .secrets/discord.json, outside everything git tracks. It is never sent back to this page; the field above shows it masked. Cloud sweeps do not read that file. They read the repository secret, which you set once with gh secret set DISCORD_WEBHOOK_URL. When that variable is present it wins, so a cloud run always posts where the secret says.

Where the prices come from

Press Check now and each site is asked for one real price. That is the whole question: is it still working. A site that has moved its URL or renamed a CSS class stops the sweep without stopping the code, and when that happens the card opens a Repair box with the strings to change — you never need it until then. Deleting data/sources.json always restores the built-in defaults.

Volatility probe

Three fixed routes sampled every two hours, to decide whether daily sweeping is often enough. Net move is first observation to last — the figure that says whether a fare is running away from you.
